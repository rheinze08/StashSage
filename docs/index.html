Using App In-Game

  1. Select or hover over the item in game for which you’d like to see historical price trends and predictions.
  2. Press CTRL+Q to bring up the overlay.
  3. Review your offer history visualization, item price predictions, and the last 5 player trade offers.
  4. Note: item price valuations only available for body armour, helmet, gloves, boots in beta!

StashSage Install Video

Installation (Windows Only)

  1. Download StashSageInstaller.zip (above).
  2. Extract the ZIP anywhere (e.g. your Downloads folder).
  3. Right-click → Scan with Microsoft Defender.
      PyInstaller apps can trigger a false Trojan alert. A manual scan clears it.
  4. Double-click StashSage.exe. If Windows SmartScreen appears, choose More info → Run anyway.
  5. Finish the installer and launch StashSage.
  6. Set your Steam / GGG log paths; click Update Settings & Reload.
  7. (Optional) Add your Discord IDs (see below) and choose Update Settings & Reload.

Discord Bot Setup Video

Discord Bot Setup  •  Discord Bot Setup Guide (.docx)

  1. Create a new application at the Discord Developer Portal.
  2. In the Bot tab enable Message Content Intent.
  3. Invite the bot to a private server. Don’t delete this server!
  4. DM the bot once so it can DM you back.
  5. Copy the bot token → paste into Discord Bot Token.
  6. Enable Developer Mode in Discord → right-click your name → Copy User ID → paste into Discord User ID.
  7. Click Update Settings & Reload → you’ll receive a confirmation DM.
