Using Price History and Price Aura

  1. Select or hover over the item in game for which you’d like to see historical price trends and predictions.
  2. Press CTRL+1 to bring up the overlay.
  3. Review your offer history visualizations and item price aura (red=worst, green=best).
  4. Note: item price valuations not available for main-hands and off-hands in beta!
  5. Note: app is currently optimized for Windowed Fullscreen!

Using Price Mirror

  1. Select or hover over the item in game for which you’d like to see predictions.
  2. Press CTRL+2 to bring up the overlay.
  3. Review your high-level summary of 10 most similar item prices and compare your item to the results.
  4. Note: item price valuations not available for main-hands and off-hands in beta!
  5. Note: app is currently optimized for Windowed Fullscreen!

Discord Bot Setup  •  Discord Bot Setup Guide (.docx)

  1. Create a new application at the Discord Developer Portal.
  2. In the Bot tab enable Message Content Intent.
  3. Invite the bot to a private server. Don’t delete this server!
  4. DM the bot once so it can DM you back.
  5. Copy the bot token → paste into Discord Bot Token.
  6. Pro Tip: save this somewhere locally so you don't need to re-copy it later!
  7. Enable Developer Mode in Discord → right-click your name → Copy User ID → paste into Discord User ID.
  8. Click Update Settings & Reload → you’ll receive a confirmation DM.
