⬇️ Download Installer (.zip)

First‑Time Installation (Windows only)

  1. Download StashSageInstaller.zip (above).
  2. Extract the ZIP anywhere (e.g. your Downloads folder).
  3. Right‑click → Scan with Microsoft Defender.
      PyInstaller apps can trigger a false Trojan alert. A manual scan clears it.
  4. Double‑click StashSage.exe. If Windows SmartScreen appears, choose More info → Run anyway.
  5. Finish the installer and launch StashSage.
  6. Set your Steam / GGG log paths; click Save Config & Restart.
  7. (Optional) Add your Discord IDs (see below) and save.

Discord Bot Setup  •  Full how‑to (.docx)

  1. Create a new application at the Discord Developer Portal.
  2. In the Bot tab enable Message Content Intent.
  3. Invite the bot to a private server via OAuth URL (permissions=8).
  4. DM the bot once so it can DM you back.
  5. Copy the bot token → paste into Discord Bot Token.
  6. Enable Developer Mode in Discord → right‑click your name → Copy User ID → paste into Discord User ID.
  7. Click Save Config & Restart → you’ll receive a confirmation DM.
