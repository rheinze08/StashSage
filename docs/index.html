Using Overlay In-Game

  1. Select or hover over the item in game for which you’d like to see price predictions.
  2. Press CTRL+1 to bring up the (unfiltered) prediction overlay.
  3. Press CTRL+2 to bring up the mod filters and filtered prediction overlay.
  4. Review the predictions (#1 = xgboost, #2 = knn) and compare to similar items.

Notes for Using the Tool

  1. All modeling is based on current (unsold) offers; the data is extremely noisy; even if an item is reasonably priced, it may still not sell.
  2. Models #1 (xgb) and #2 (knn) may not agree on predictions, but both approaches are valid.
  3. Model #1 visualization shows how the item's prediction compares to all other items in same category.
  4. Care when using Model #2 to price items with less than 6-mods, as comparing to 6-m items can be tricky.
  5. For example, is a 4-m item more similar to (a) 4-m item with the same 4-m but very different values, or (b) a 5-m item with 3 of the same mods with exact same values, and 2 non-overlapping mods?
  6. Models currently trained to price rare items, not magic or uniques.
  7. Models currently available for all armour slots, jewels, wands, sceptres, quivers.
  8. Models currently unavailable for main-hands and other off-hands.
  9. Overlay is currently optimized for Windowed Fullscreen only.
  10. New models trained daily and posted for download, no auto-update capability.

Modeling Notes

  1. The model currently ignores "mark of the abyssal lord", "allocates passive", "on corruption" mods.
  2. The model currently ignores "corrupted", "fractured", "descrated" item statuses.
  3. The model currently ignores socketables as they are not an underlying modifier.
  4. Items with quality and socketables have had their modifier values normalized to their base values.
  5. # and #% increases to base ar/ev/es have been encoded into the inflated ar/ev/es value as a single modifier.

Discord Bot Setup  •  Discord Bot Setup Guide (.docx)

  1. Create a new application at the Discord Developer Portal.
  2. In the Bot tab enable Message Content Intent.
  3. Invite the bot to a private server. Don’t delete this server!
  4. DM the bot once so it can DM you back.
  5. Copy the bot token → paste into Discord Bot Token.
  6. Pro Tip: save this somewhere locally so you don't need to re-copy it later!
  7. Enable Developer Mode in Discord → right-click your name → Copy User ID → paste into Discord User ID.
  8. Click Update Settings & Reload → you’ll receive a confirmation DM.
